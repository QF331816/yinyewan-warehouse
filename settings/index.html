这套系统怎么分层

前端 UI / 中端逻辑 / 后端数据

前端 UI 层

Next.js App Router + Tailwind + 自建设计系统。页面全部是服务器组件，交互部件（单据编辑器、盘点录入、新增物品）单独做成客户端组件。

app/**/page.tsxcomponents/ui/*

中端逻辑层

Server Actions 处理提交，queries 负责聚合计算，actions 负责过账与状态机。库存永远由流水推导，不维护冗余余额。

lib/queries.tslib/actions.ts

后端数据层

当前是 data/db.json 单文件存储，读写集中在 lib/store.ts。换成 Prisma + PostgreSQL 时，只需替换 readDB / mutate 两个函数。

lib/store.tsdata/db.json

原型阶段没有登录与权限：这是给单个保管员用的内部工具。真正上线时需要补登录、角色（保管员 / 领用人 / 审批） 与操作日志，这些字段与表结构在调研文档里已经预留。
